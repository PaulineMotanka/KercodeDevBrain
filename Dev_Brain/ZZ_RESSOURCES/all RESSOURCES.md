## Bonnes habitudes de travail

### Vérifier les informations

- Privilégier la documentation officielle (MDN, Git, ECMAScript) pour vérifier les informations techniques.
    
- Utiliser les cours et tutoriels pour découvrir et comprendre les notions.
    
- Pratiquer régulièrement avec les jeux et exercices interactifs.
    
- Ne pas simplement copier du code trouvé sur Internet : essayer de comprendre chaque propriété, fonction ou instruction.
    
- Vérifier la compatibilité des fonctionnalités avec les navigateurs.
