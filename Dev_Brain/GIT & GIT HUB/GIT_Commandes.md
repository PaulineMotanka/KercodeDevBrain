| Commande                                         | Description                                                                                                                                                                 |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `git help <commande>`                            | Donne des informations sur l'utilisation de la commande voulue                                                                                                              |
| `git clone <url du repo>`                        | Cloner (télécharger) un repo distant existant                                                                                                                               |
| `git init`                                       | Initialiser un dépôt git, à lancer a la création du projet                                                                                                                  |
| `git status <fichier>`                           | Affiche le status des éléments du repo (Stagé/Modifié/Supprimé/ etc ...)                                                                                                    |
| `git add <fichier/dossier>`                      | Ajouter des fichiers à l'index (stage)                                                                                                                                      |
| `git rm --cached <fichier/dossier>`              | Retire un fichier/dossier du repo                                                                                                                                           |
| `git commit -m [-a]`                             | Enregistrer les modifications staged (qui sont enregistrées avec `git add`) avec un message                                                                                 |
| `git push [-u <nom du remote> <branche a push>]` | Pousser les modifications sur le dépot distant  <br>**ATTENTION :** Le `-u` est obligatoire la première fois, puis `git push` suffit (sauf en cas de changement de branche) |
| `git fetch`                                      | Récupère la dernière version du repo distant                                                                                                                                |
| `git pull`                                       | Remplace le repo local par le contenu du repo distant                                                                                                                       |
| `git branch [-m] [nom de branche]`               | Voir la liste des branches, ou changer de branche si on spécifie un nom. le `-m` permet de définir la branche principale                                                    |
| `git log`                                        | Affiche l'historique des commits                                                                                                                                            |
