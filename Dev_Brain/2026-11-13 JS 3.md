Les boucles
## Boucles dont on connait le nombre d'itération :

**Itération =** passage dans la boucle

`for (let i = 0; i < 5; i++) {     console.log("La variable d'index est égale à " + i) };`

`(let i = 0; i < 5; i++)` Dans cette partie du code :

- `let i = 0` | On à créé une variable qui servira de compteur (index)

- `i < 5` | C'est la condition pour qu'on refasse une itération. Dans ce cas : Tant que i (la variable compteur) est plus petit que 5 on refait un passage dans la boucle

- `i++` | Cette partie s'execute à chaque fin d'itération.

- `console.log(...... + i)` | A l'interieur de notre boucle, il est tout a fait possible d'utiliser la varibale i (compteur) que l'on a définit. Si vous avez bien compris sa valeur change a chaque itération.

### Voila ce qui se passe concrètement quand on execute ce code :

**Toute premiere itération :**

- `let i = 0` | i vaut 0

- `i < 5` | On verifie que i est plus petit que 5

- `i` est plus petit que 5 alors on execute le code a l'interieur de la boucle

- La variable `i` dans le console.log() vaut `0`

- `i++` | fin du code de la boucle, donc on ajoute 1 a "i" (compteur) et on recommence

**2e itération :**

- `i` vaut 1

- On verifie que `i` est plus petit que 5

- La condition est toujours valide donc on execute le code

- la variable `i` dans le console.log vaut 1

- fin du code de boucle alors on ajoute 1 à `i`

La boucle ne s'arretera pas tant que `i` est plus petit que 5. (vu que c'est la condition qu'on a définit)
